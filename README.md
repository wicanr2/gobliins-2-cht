## 文字放在哪

跟前作不同：二代的文字**不在 `.TOT` 裡**（`textsOffset == 0`），而是放在同名的
語言側檔，由引擎依語言挑：

| 副檔名 | 語言 | 則數 |
|---|---|---|
| `.dat` | **法（原文）** | 849 |
| `.ang` | 英／預設 | 797 |
| `.usa` | 美 | 774 |
| `.all` | 德 | 746 |
| `.esp` | 西 | 745 |
| `.ita` | 義 | 745 |

`.dat` 是**法文**不是資料檔——副檔名完全看不出來，而它是最完整的一份，
所以拿它當翻譯的來源語言。
